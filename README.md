# 🚀 DevTinder

DevTinder is a MERN stack application designed to **connect developers** with each other.  
Think of it as a developer-focused networking platform where devs can find, connect, and collaborate.

---

## 🔥 Features

- 👤 **User Authentication** (Signup/Login with JWT)
- 🔒 **Secure Sessions** with JSON Web Tokens
- 📡 **MERN Stack** (MongoDB, Express, React, Node.js)
- ⚡ **State Management** with Redux
- 🖥️ **Responsive UI** for smooth experience
- 🤝 Connect, discover, and collaborate with developers

---

## 🛠️ Tech Stack

**Frontend:**
- React.js
- Redux
- Tailwind CSS / SCSS (if you used it)

**Backend:**
- Node.js
- Express.js
- MongoDB (Mongoose ODM)

**Authentication & Security:**
- JWT (JSON Web Tokens)
- Bcrypt (if you used it for password hashing)
